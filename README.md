# Nuvio covers

Capas animadas (WebP 960x540) da coleção "Streaming Services" para o Nuvio, e os ficheiros da coleção.

- `streaming/`: uma capa por plataforma.
- `collections/nuvio-streaming-services.json`: versão em filas.
- `collections/nuvio-streaming-services-menu.json`: versão com menu de separadores (temas, anos, recentes).

Importar: nuvio.tv/account, separador Collections, Import.

As capas mostram logótipos e posters que pertencem aos respetivos donos. Uso pessoal, não comercial.
